# SOFTWARE FACTORY

مصنع برمجيات بالذكاء الاصطناعي — **النسخة التأسيسية v0.1**.

واجهة عربية RTL لإدارة المشاريع، توثيق المتطلبات واعتمادها، متابعة سير عمل محفوظ، ثم مراجعة قالب قابل للتشغيل وتنزيله.

> **الحدود الحالية:** سير العمل محاكاة حتمية، لا يوجد نموذج AI متصل. المخرجات قالب لوحة مهام ثابت، وليست كودًا مولّدًا من وصفك. هذه مساحة تطوير مشتركة بلا مصادقة، فلا تُدخل أسرارًا أو بيانات عملاء ولا تنشرها كخدمة عامة.

## ما يعمل الآن

- لوحة مشاريع بإحصائيات فعلية، وبحث وتصفية وحذف بتأكيد.
- إنشاء مشروع من وصف عربي أو مثال جاهز.
- تشغيل تجريبي بحالات محفوظة في SQLite، مع منع تشغيلين نشطين للمشروع نفسه.
- مراجعة المتطلبات وتعديلها وحفظها ثم اعتماد النسخة الحالية؛ رفض الطلبات القديمة والمتعارضة.
- إيقاف مؤقت للمحاكاة، إلغاء تشغيل، ومحاولات جديدة مع سجل لكل محاولة.
- تصفح الملفات، ومعاينة قالب لوحة مهام ثابت داخل iframe معزول.
- فحوص **بنية الحزمة فقط**؛ لا ينفذ المصنع الكود على الخادم.
- اعتماد التسليم ثم تنزيل ZIP يضم القالب والمتطلبات والخطة وتقرير الفحص.
- واجهة متجاوبة، خط عربي محلي دون Google Fonts، ونوافذ حوار تدعم لوحة المفاتيح.

المحاكاة تتقدم عند فتح مساحة المشروع فقط. إغلاقها يوقف إرسال الخطوات، ولا يفقد الحالة المحفوظة. قد تنتهي الخطوة التي أُرسلت بالفعل قبل الإغلاق.

## التشغيل المحلي

المتطلبات: **Node.js 22.17+** و**Python 3.11+**. الأوامر التالية لنظام Linux أو macOS.

```bash
npm ci
python3 -m venv .venv
.venv/bin/python -m pip install -r services/api/requirements.txt
```

في نافذة أولى:

```bash
npm run dev:api
```

وفي نافذة ثانية:

```bash
npm run dev
```

افتح `http://localhost:3000`. واجهة API التوثيقية على `http://localhost:8000/docs`، وفحص الصحة على `/api/v1/health`.

في المعاينة السحابية، افتح **واجهة مصنع البرمجيات — المنفذ 3000**. المتصفح يستخدم `/api/v1` على الأصل نفسه، وNext.js يمرر الطلبات إلى FastAPI؛ لا يحتاج المتصفح للوصول إلى `localhost` على جهاز المستخدم.

### تجربة أول مشروع

1. اضغط **جرّب مشروعًا تجريبيًا**، ثم **إنشاء المشروع**.
2. اضغط **ابدأ التشغيل التجريبي**.
3. راجع المتطلبات. إن عدّلتها، احفظ التعديلات قبل **اعتماد ومتابعة**.
4. افتح **الملفات** وراجع `report.json` و**معاينة القالب**.
5. اضغط **اعتماد التسليم** ثم **تنزيل المشروع ZIP**.
6. فك الضغط وافتح `index.html` في متصفح حديث. تعمل لوحة المهام دون تبعيات أو خدمات خارجية.

## الإعدادات والبيانات

| الإعداد | الافتراضي | كيفية التغيير |
|---|---|---|
| `FACTORY_DB` | `.data/factory.sqlite3` في جذر المستودع | متغير بيئة لعملية API |
| `API_ORIGIN` | `http://127.0.0.1:8000` | انسخ `apps/web/.env.example` إلى `apps/web/.env.local` |
| `NEXT_TELEMETRY_DISABLED` | يضبط حسب بيئة Next.js | ضع `1` لتعطيل telemetry الخاص بإطار Next.js |

مثال قاعدة بيانات منفصلة:

```bash
FACTORY_DB=.data/my-workspace.sqlite3 npm run dev:api
```

- لا توجد مفاتيح نماذج مطلوبة أو مخزنة في هذه النسخة.
- المشاريع والتشغيلات والأحداث والمخرجات محفوظة في قاعدة SQLite. مجلد `.data/` مستثنى من Git؛ احفظ نسخة احتياطية منه إذا أردت الاحتفاظ ببياناتك قبل نقل البيئة.
- معاينة القالب مؤقتة ولا تشارك التخزين أو جلسة الأصل المضيف. الحفظ المحلي في الملف المنزّل يعتمد على سماح المتصفح بتخزين صفحات الملفات المحلية.
- حذف مشروع يزيل تشغيلاته وملفاته وسجلّه من قاعدة البيانات. لا يحذف ملفات ZIP التي سبق تنزيلها.
- الحد التجريبي: 100 مشروع، و20 تشغيلًا لكل مشروع. لا توجد مهام خلفية أو فوترة.

## الفحوص

```bash
npm run format:check
npm run typecheck
npm run lint:api
npm run test:api
npm run build
```

اختبارات المتصفح القياسية:

```bash
npx playwright install --with-deps chromium
npm run test:e2e
```

بديل Linux في بيئات لا تصل إلى CDN المتصفحات، يستخدم Chromium المعبأ عبر npm:

```bash
npm run test:e2e:bundled
```

يشغّل Playwright الخدمتين تلقائيًا عند غيابهما، أو يعيد استخدام الخدمتين المحليتين الجاريتين خارج CI. تختبر حالات المتصفح مشاريعها الخاصة وتحذفها، ولا تمسح مساحة العمل. في CI تُستخدم `.data/e2e.sqlite3`.

اختبارات الخادم تغطي الاعتماد الإلزامي، الحفظ بعد إعادة التشغيل، التزامن، idempotency، التحقق من المدخلات، الإلغاء والحذف وتنزيل الحزمة. اختبارات المتصفح تختبر المسار الفعلي وواجهة الهاتف وقالب المهام؛ لا ينبغي الخلط بينها وبين فحوص البنية الثلاثة المعروضة داخل التطبيق.

أضيف سير عمل GitHub Actions في `.github/workflows/ci.yml` لتشغيل هذه الفحوص عند push أو pull request. وجود الملف لا يعني أن تشغيله على GitHub قد حدث بالفعل.

## الهيكل

```text
apps/web/              Next.js + React + TypeScript؛ واجهة المصنع ووكيل API
services/api/factory/  FastAPI + SQLite؛ آلة حالات ومعاملات ذرية
services/api/tests/    اختبارات API بقاعدة مستقلة لكل اختبار
packages/templates/   قالب لوحة المهام الموثوق
scripts/              مساعد اختبار المتصفح في البيئات المقيدة
tests/e2e/            اختبارات Playwright
docs/                 الخطة والقرارات وحدود التنفيذ
```
